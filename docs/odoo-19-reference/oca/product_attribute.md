# OCA/product-attribute


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/product-attribute/tree/19.0

## Purpose

OCA product attribute and variant modules: attribute set management, multi-image products, packaging, and product completeness scoring. Use when extending product data modelling.
