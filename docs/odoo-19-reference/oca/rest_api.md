# OCA/rest-api


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/rest-api/tree/19.0

## Purpose

OCA REST API addon collections built on top of rest-framework. Covers sale order, stock, and partner REST endpoints. Use when exposing Odoo business objects via REST.
