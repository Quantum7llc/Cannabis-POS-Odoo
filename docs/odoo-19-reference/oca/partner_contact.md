# OCA/partner-contact


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/partner-contact/tree/19.0

## Purpose

OCA partner/contact extensions: address completion, birthdate, contact tags, company type, postal codes, opening hours, and duplicate merging. Use when extending the res.partner model.
