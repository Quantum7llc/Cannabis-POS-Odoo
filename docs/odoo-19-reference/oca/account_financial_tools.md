# OCA/account-financial-tools


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/account-financial-tools/tree/19.0

## Purpose

OCA financial tools: account lock dates, journal security, fiscal year management, and accounting period controls. Use for financial period management and access control.
