# OCA Community Modules — Odoo 19.0

Curated OCA repositories relevant to POS, accounting, inventory, and partner management.

- [OCA/pos](pos.md) — OCA Point of Sale extensions: barcode scanning, loyalty programs, multi-currency, receipt customisation, and cashier session management
- [OCA/account-invoicing](account_invoicing.md) — OCA invoice extensions: incoterms, due-date reminders, invoice validation workflows, payment terms, and invoice sequence customisations
- [OCA/account-payment](account_payment.md) — OCA payment modules: batch payments, payment order workflows, SEPA, and payment mode configuration
- [OCA/account-financial-tools](account_financial_tools.md) — OCA financial tools: account lock dates, journal security, fiscal year management, and accounting period controls
- [OCA/account-analytic](account_analytic.md) — OCA analytic accounting extensions: analytic distribution defaults, required analytics, and analytic account management
- [OCA/account-reconcile](account_reconcile.md) — OCA bank statement and reconciliation modules: statement import helpers and automated reconciliation rules
- [OCA/stock-logistics-warehouse](stock_warehouse.md) — OCA warehouse extensions: stock aging reports, procurement rules, slow-moving stock alerts, and warehouse configuration helpers
- [OCA/stock-logistics-barcode](stock_barcode.md) — OCA barcode scanning for inventory: lot/serial scanning, location barcodes, and scan-based receipt/delivery validation
- [OCA/stock-logistics-workflow](stock_workflow.md) — OCA stock workflow modules: picking split, partial transfer rules, and delivery state management
- [OCA/product-attribute](product_attribute.md) — OCA product attribute and variant modules: attribute set management, multi-image products, packaging, and product completeness scoring
- [OCA/sale-workflow](sale_workflow.md) — OCA sales workflow extensions: order approval, double validation, invoice from picking, and sale exception handling
- [OCA/partner-contact](partner_contact.md) — OCA partner/contact extensions: address completion, birthdate, contact tags, company type, postal codes, opening hours, and duplicate merging
- [OCA/l10n-usa](l10n_usa.md) — OCA US localization: state-level tax configuration, US chart of accounts adjustments, and American date/address formats
- [OCA/rma](rma.md) — OCA Return Merchandise Authorisation: RMA orders, customer return workflows, refund/replace/repair routing, and RMA reporting
- [OCA/web](web.md) — OCA web client extensions: list view enhancements, pivot drill-down, form buttons, keyboard shortcuts, tree-view extras, and UI utilities
- [OCA/server-tools](server_tools.md) — OCA server utilities: sequence reset, database cleanup, attachment management, scheduled action logging, and configuration export
- [OCA/reporting-engine](reporting_engine.md) — OCA reporting framework: SQL-based reports, Aeroo/ODF templates, report to attachment, and report custom filename rules
- [OCA/server-auth](server_auth.md) — OCA authentication modules: TOTP two-factor, OAuth2, SAML2, password policy, and login audit logging
- [OCA/rest-framework](rest_framework.md) — OCA REST framework: FastAPI-based REST endpoints, versioned APIs, JWT authentication, and OpenAPI schema generation
- [OCA/rest-api](rest_api.md) — OCA REST API addon collections built on top of rest-framework
