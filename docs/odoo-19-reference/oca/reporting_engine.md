# OCA/reporting-engine


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/reporting-engine/tree/19.0

## Purpose

OCA reporting framework: SQL-based reports, Aeroo/ODF templates, report to attachment, and report custom filename rules. Use when building custom reports beyond standard QWeb.
