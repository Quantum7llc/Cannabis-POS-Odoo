# OCA/web


> **OCA Community Modules (19.0)**
> Source: https://github.com/OCA/web/tree/19.0

## Purpose

OCA web client extensions: list view enhancements, pivot drill-down, form buttons, keyboard shortcuts, tree-view extras, and UI utilities. Use when improving the Odoo web interface.
